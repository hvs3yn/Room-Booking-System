# AI Usage Report — Room Booking System

This report explains how our team used AI tools while building the project.
Each member writes **only their own section** (to avoid merge conflicts).

## 1. Team approach (shared)

- **Spec-driven development:** before writing code we wrote `docs/REQUIREMENTS.md` (business
  requirements, user stories, acceptance criteria) and `docs/SPEC.md` (exact architecture,
  file ownership, function signatures, API contract, error messages). With AI help, these
  documents were then split into one self-contained task file per member (`tasks/*.md`).
- **AI agents per member:** each member gave their task file to an AI coding assistant. Because
  every interface was fixed in the spec, the four parts were built in parallel and fit together.
- **Human responsibility:** every line of AI-generated code was read, run and tested by the
  member who owns it. We had to be able to explain all of it to the teacher.
- **AI code review:** before opening each Pull Request we asked an AI to review the diff, and
  a human teammate then reviewed the PR too.
